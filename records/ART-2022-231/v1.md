# ART-2022-231 - Revision v1
Recorded: 2022-12-05
Title: Data-Efficient Surrogate Models for Turbulent Flow Prediction
Authors: Marcus Feld, Chloe Renard
Venue: Physics of Fluids

## Abstract
We propose a data-efficient surrogate that predicts turbulent velocity fields from sparse sensor measurements. A convolutional encoder maps sensor readings to a latent state, and a Fourier neural operator evolves the state forward in time. On channel-flow and airfoil datasets the surrogate predicts one-step fields within eight percent relative error. Long-horizon rollouts drift, and the reported error metric was later found to be computed on overlapping windows that inflate the apparent accuracy; the claims in this record should not be used.
